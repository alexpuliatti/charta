# Beyond Taking Turns

By Bruce Liu.

Two interactive experiments in AI conversation interface design.

## Feedforward

Shows the AI’s plan while the user types, before the message is sent. It explores giving users an early opportunity to correct the direction instead of waiting for a completed response.

## Leaving Blanks

Leaves missing details open for the user to fill rather than making a guess. The response can continue as those details are supplied.

The page compares these interactions with conventional chat, where each message is a separate turn.
